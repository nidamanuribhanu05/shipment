# Shipflow: Excel Shipment Web App Demo

Open `index.html` to preview the interface locally, or publish the **contents of this folder** to GitHub Pages. See [GITHUB_DEPLOY_GUIDE.md](GITHUB_DEPLOY_GUIDE.md) for the exact steps.

Features: interactive dashboard, Excel-style editable spreadsheet, import `.xlsx` and CSV files, browser-side `.xlsx` download, prepare a workbook in the dispatch form, simulated Send button, simulated admin/user views, and local demo history.

**Important:** This is a public static demo. No real emails are sent. No files are saved to SharePoint. Administrator permissions are not enforced. Never enter private company or customer information into a public demo.

The companion Azure starter project will be used later for authentication, actual sending and SharePoint integration. Its integration requires additional hardening before production.
